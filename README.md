# Deux locaux à vendre, Paris 17e

Présentation animée de deux locaux de bureaux de 77 m² dans le 17e arrondissement de Paris.

- `index.html` : la page de présentation (ouvrir dans un navigateur).
- `fiches/` : les deux fiches de vente au format PDF.
- `images/` : les photos utilisées par la page.
- `data/locaux.json` et `data/locaux.csv` : les chiffres publics de chaque local.

L'adresse exacte et les documents détaillés sont remis après signature d'un accord de confidentialité.
